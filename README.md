# 基于 STM32 的联网墨水屏时钟

## 项目简介

本项目基于 **STM32F103RCT6** 与 **FreeRTOS**，实现了一款支持 **NTP 自动对时**、**实时天气显示**、**按键调时**、**掉电走时** 与 **WiFi 配置持久化存储** 的联网墨水屏时钟。  
采用 1.54 寸墨水屏（SSD1681）作为显示终端，画面零闪烁、断电不丢画面；通过 ESP8266 连接网络，自动同步网络时间并获取心知天气数据。

## 功能特性

- **墨水屏显示**：日期、时间、温度与天气图标，每分钟局刷一次，定期全刷清残影。
- **自动对时**：上电自动连接 WiFi，通过 NTP 获取网络时间并写入 DS3231；含双闸门校验，防止无效时间写入。
- **掉电走时**：集成 DS3231 RTC，掉电后依靠纽扣电池继续走时，开机自动校验 OSF 标志。
- **天气显示**：通过 HTTP 请求心知天气 API，解析 JSON 后在屏幕底部显示温度与天气图标。
- **按键调时**：3 个按键（SET / UP / DOWN）实现消抖、长按检测与菜单状态机，支持设备端手动调时。
- **配置持久化**：WiFi SSID/密码/NTP 服务器存储于内部 Flash，支持串口命令行在线修改，免重新烧录。
- **FreeRTOS 多任务**：任务划分清晰，使用信号量、互斥锁与任务通知实现无阻塞解耦。

## 硬件设计

### 硬件清单

| 模块 | 型号 | 说明 |
|------|------|------|
| 主控 | STM32F103RCT6 | 48KB RAM，256KB Flash |
| 墨水屏 | 1.54 寸 SSD1681 | 200×200 像素，SPI 接口 |
| RTC | DS3231 | I2C 接口，带纽扣电池 |
| WiFi | ESP8266（AT 固件） | UART 接口 |
| 按键 | 3 个轻触按键 | SET / UP / DOWN |
| 调试 | USB-TTL | 接 USART1，用于串口打印 |

### 接线说明

| 外设 | STM32 引脚 | 说明 |
|------|------------|------|
| 墨水屏 | PA5 (SCK), PA7 (MOSI), PA4 (CS), PA3 (DC), PA2 (RST), PA1 (BUSY) | SPI1 |
| DS3231 | PB6 (SCL), PB7 (SDA), PA8 (SQW) | I2C1，SQW 用于唤醒（预留） |
| ESP8266 | PB10 (TX), PB11 (RX) | USART3 |
| 按键 | PA0 (SET), PB0 (UP), PB1 (DOWN) | 上拉输入，按下接 GND |
| 调试串口 | PA9 (TX), PA10 (RX) | USART1 |

> 语音模块（VC-02）已停用，UART4（PC10/PC11）相关代码保留但未启用。

## 软件架构

### 技术栈

- **MCU**：STM32F103RCT6
- **RTOS**：FreeRTOS (CMSIS-RTOS V2)
- **开发工具**：STM32CubeMX + Keil MDK
- **驱动库**：HAL 库
- **通信协议**：SPI、I2C、UART、DMA、IDLE 中断
- **网络**：ESP8266 AT 指令、NTP、HTTP、JSON
- **存储**：内部 Flash 读写

### FreeRTOS 任务划分

| 任务 | 优先级 | 主要职责 |
|------|--------|----------|
| TASK_INIT | High | 初始化 DS3231、墨水屏，首次全刷，随后自毁 |
| TASK_SHOW | AboveNormal | 墨水屏刷新：每分钟局刷、定期全刷、天气更新 |
| TASK_READ | Normal | 每秒读取 DS3231，更新全局时间变量 |
| TASK_KEY | Normal | 按键扫描（消抖 + 长按），处理调时菜单 |
| TASK_WIFI | Normal | WiFi 连接、NTP 对时、天气获取，每小时循环 |

## 核心模块实现

### 墨水屏驱动

- 从零编写 SSD1681 SPI 驱动，解决字库位序镜像、物理坐标反转问题。
- 实现局刷与全刷两种模式：每分钟局刷一次，每 10 分钟全刷一次清除残影。
- 自建 8×16 ASCII 字库，支持字符串绘制与天气图标绘制。

### RTC 掉电走时

- 通过 I2C 读写 DS3231，支持突发读取 7 个寄存器，保证数据一致性。
- 写入时间后回读校验，并清除 OSF 标志。
- 开机时检查 OSF，若掉电则标记时间不可信，等待 NTP 校准。

### WiFi 与 NTP 对时

- 使用 UART + DMA + IDLE 中断接收 ESP8266 数据，避免轮询丢包。
- 通过 AT 指令连接 WiFi、配置 NTP 服务器、查询网络时间。
- 双闸门校验：先检查年份、时分秒范围，再换算为两位年/BCD 格式后二次校验，防止 1970 年时间写入 RTC。

### 天气获取与显示

- 通过 HTTP GET 请求心知天气 API，解析 JSON 中的 `temperature` 与 `code` 字段。
- 根据天气代码绘制对应图标（晴、多云、阴、雨、雪），并显示温度值。

### 按键调时

- 3 个按键（SET / UP / DOWN）实现消抖（3 次采样确认）与长按检测（≥1 秒）。
- 状态机：NORMAL → SET_HOUR → SET_MIN → 保存并回到 NORMAL。
- 调时模式下，`task_read` 不覆盖用户正在编辑的时间。

### Flash 配置持久化

- 使用内部 Flash 最后一页（`0x0803F800`）存储 WiFi 配置。
- 结构体包含魔数、SSID、密码、NTP 服务器与校验和。
- 支持串口命令行在线修改配置，保存后自动重启生效。

## 使用说明

### 编译与烧录

1. 使用 STM32CubeMX 打开工程，确认外设配置无误。
2. 使用 Keil MDK 编译，烧录至 STM32F103RCT6。
3. 确保 `FreeRTOSConfig.h` 中 `configTOTAL_HEAP_SIZE` 足够大（建议 ≥ 24576）。

### 串口命令行

上电后 15 秒内，可通过 USART1（115200）发送以下命令：

| 命令 | 说明 |
|------|------|
| `SETWIFI:ssid,pass` | 修改 WiFi 账号密码，保存后自动重启 |
| `SETNTP:服务器地址` | 修改 NTP 服务器，保存后自动重启 |
| `SHOWCFG` | 显示当前 Flash 中保存的配置 |

### 首次配置 WiFi

1. 烧录后，打开串口助手（115200）。
2. 上电后 15 秒内发送 `SETWIFI:你的SSID,你的密码`。
3. 系统保存配置并自动重启，之后将使用新 WiFi 连接网络。

## 已知问题与注意事项

- **ESP8266 睡眠功能已禁用**：曾尝试 `AT+SLEEP`，但模块单独供电时容易睡死，需冷启动复位，故暂时禁用。
- **低功耗 STOP 模式未启用**：手动调用 `HAL_PWR_EnterSTOPMode` 会打乱 FreeRTOS tick，暂未使用；后续可考虑 tickless idle。
- **UART4 中断占位变量**：语音功能已停用，但 `stm32f1xx_it.c` 中仍引用 `voice_rx_flag` 等变量，故在 `freertos.c` 中保留定义，不影响运行。
- **重新生成代码注意**：CubeMX 会重置 `configTOTAL_HEAP_SIZE`，每次生成后需手动改回。

## 后续可扩展方向

- **低功耗**：使用 FreeRTOS tickless idle 实现 STOP 模式，配合 DS3231 SQW 唤醒，降低平均电流。
- **硬件断电 ESP8266**：用 GPIO 控制 MOS 管，对时完成后彻底断电，进一步省电。
- **语音播报**：更换为 SYN6288 等 TTS 模块，实现整点语音报时。
- **更多天气信息**：显示空气质量、湿度、风速等。
